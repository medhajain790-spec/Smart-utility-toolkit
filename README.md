# Smart Utility Toolkit

This is a beginner-friendly Node.js lab assignment using only built-in modules.

## Run the programs

```bash
node calculator.js add 10 5
node app.js
node server.js
node fileManager.js
node dice.js
```

Open `http://localhost:3000` after running `server.js`. Use `Ctrl + C` to stop it.

Calculator operations: `add`, `sub`, `mul`, and `div`.
